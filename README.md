# Ride with GPS for Karoo

Ride with GPS on your Hammerhead Karoo: your routes, collections and events, turn-by-turn navigation, offline maps, and rides that upload straight to your Ride with GPS account.

It's the same Ride with GPS Android app that's on Google Play. On a Karoo it switches to a head-unit layout built for the Karoo's screen and buttons.

> **Not released yet.** There's nothing to install here yet. The first release will be attached under [Releases](../../releases), and this page will have the install steps.

## Install

You need a current-generation Karoo on Karoo software 1.538.2049 or later, connected to Wi-Fi, and the Hammerhead Companion app on your phone, paired with the Karoo.

1. On your phone, open this page.
2. Long-press the `ridewithgps.apk` link on the [latest release](../../releases/latest) and share it to the **Hammerhead Companion** app.
3. On the Karoo, tap **Install**.
4. Open **Ride with GPS** on the Karoo and sign in by scanning the QR code with your phone.

The app is about 120 MB, so give the download a few minutes on the Karoo's Wi-Fi.

## Update

When a new version is out, Ride with GPS says **Update available** on its home screen. On the Karoo, long-press Ride with GPS in **Apps**, or open **Extensions**, and tap **Update**.

## Beta testers

If we've asked you to help test new versions, install from the [Beta release](../../releases/tag/beta) instead, with the same steps and its `ridewithgps-beta.apk` link. It's a separate app with DEV on its icon, and your Karoo offers each new beta as an Update. Beta builds can be rough, so if you're not testing with us, use the regular release.

## Karoo 2

The Companion app can't install apps on a Karoo 2. If you're comfortable with developer tools, you can install the same file with `adb install ridewithgps.apk`.

## Help

Questions or problems: contact Ride with GPS support at https://ridewithgps.com/help and mention you're on a Karoo.
